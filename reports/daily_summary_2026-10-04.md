- เควสต์ ความคืบหน้า และสถานะรับรางวัลถูกบันทึกในข้อมูลเกม เพื่อให้ชุดเควสต์ของวันเดิมไม่เปลี่ยนเมื่อปิดแล้วเปิดเกมใหม่
- การสุ่มปลาเพิ่มโอกาสเลือกปลาชนิดที่ผู้เล่นจับได้น้อยในแหล่งน้ำนั้น

## ประเภทเควสต์

เอเจนต์สุ่มจำนวนเควสต์จาก 1 ถึง 5 รายการ โดยเลือกจากประเภทต่อไปนี้โดยไม่เลือกประเภทซ้ำ:

1. **นักสำรวจน้ำจืด** — จับปลาในทะเลสาบน้ำจืด
2. **นักล่าปลาทะเล** — จับปลาในทะเลลึก
3. **ผู้พิชิตปากแม่น้ำ** — จับปลาในปากแม่น้ำน้ำกร่อย
4. **ออกเรือหาปลา** — จับปลาที่แหล่งน้ำใดก็ได้
5. **นักตกปลาร่างยักษ์** — จับปลาที่มีน้ำหนักถึงเกณฑ์

ปลาหนึ่งตัวอาจเพิ่มความคืบหน้าให้หลายเควสต์ได้ หากตรงกับเงื่อนไขของแต่ละรายการ เช่น ปลาทะเลที่หนักพออาจนับทั้งเควสต์ทะเล เควสต์ปลาหนัก และเควสต์จับปลาทั่วไป

## สูตรความยากและรางวัล

กำหนดระดับรวมของอุปกรณ์เป็น:

```text
level_score = max(0, bait_level + rod_level - 2)
```

จำนวนปลาเป้าหมายของเควสต์ทั่วไปและเควสต์แหล่งน้ำ:

```text
target = 2 + level_score
```

เควสต์ปลาหนักกำหนดจำนวนเป้าหมายและน้ำหนักขั้นต่ำแยกดังนี้:

```text
target = 1 + floor(level_score / 3)
min_weight_kg = 4.0 + 0.5 * (bait_level - 1) + 1.5 * (rod_level - 1)
```

ฐานเงินรางวัลขึ้นกับประเภทเควสต์:

```text
reward_base = 60   # เควสต์จับปลาทั่วไป
reward_base = 90   # เควสต์แหล่งน้ำ
reward_base = 140  # เควสต์ปลาหนัก
```

สูตรเงินรางวัลสุดท้าย:

```text
reward = reward_base + 25 * target + 20 * level_score
```

ดังนั้นการเพิ่มเลเวลเหยื่อหรือคันเบ็ดจะเพิ่ม `level_score` ทำให้จำนวนเป้าหมายหรือเกณฑ์น้ำหนักสูงขึ้น และเพิ่มเงินรางวัลด้วย เควสต์แต่ละรายการรับรางวัลได้ครั้งเดียว

## สูตรสุ่มปลา

1. สุ่มชนิดปลาจาก API หรือข้อมูลสำรองในแหล่งน้ำที่เลือกจำนวน 3 ครั้ง
2. นับจำนวนปลาของแต่ละชนิดที่มีอยู่ในกระเป๋าในแหล่งน้ำนั้น
3. เลือกจากชนิดที่มีจำนวนในกระเป๋าน้อยที่สุดในตัวเลือกทั้งสาม หากเสมอกันจะสุ่มเลือกจากกลุ่มที่เสมอ

วิธีนี้ยังคงสุ่มปลาได้ผ่าน `SpeciesLoader` ระหว่างที่ข้อมูลออนไลน์กำลังโหลด และให้น้ำหนักไปทางชนิดที่ผู้เล่นยังมีน้อย

## ไฟล์หลักที่เกี่ยวข้อง

- `src/ai_fishing.py` — สร้างเควสต์ ติดตามความคืบหน้า รับรางวัล และเลือกชนิดปลา
- `src/gui/pages/quest.py` — แสดงการ์ดเควสต์และแถบความคืบหน้า
- `src/gui/pages/fishing.py` และ `src/gui/presenter.py` — เชื่อมการสุ่มปลาและการจับปลากับเอเจนต์
- `src/game_state.py` — บันทึกข้อมูลเควสต์ไปกับเซฟเกม
- `src/gui/app.py` — สร้างเอเจนต์และลงทะเบียนหน้าเควสต์
- `src/gui/pages/` — แยกโค้ดหน้าจอ GUI เป็นไฟล์ตามแต่ละหน้า
