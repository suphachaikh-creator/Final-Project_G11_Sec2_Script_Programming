# สรุปงานประจำวันที่ 4 ตุลาคม 2026

## งานที่ทำ

- เพิ่มหน้า **เควสต์ตกปลา** ในเมนูเกม
- แยกหน้าจอ GUI จาก `src/gui/frames.py` เป็นโมดูลรายหน้าใน `src/gui/pages/` ได้แก่ หน้าแรก ตกปลา ร้านค้า คลังปลา และเควสต์ พร้อมไฟล์ `common.py` สำหรับส่วนที่ใช้ร่วมกัน
- เพิ่ม `src/ai_fishing.py` เป็นตัวช่วยตกปลา มีเอเจนต์ในเครื่องเป็น fallback และรองรับ Gemini API เมื่อมี key
- เพิ่มตัวเชื่อม Gemini API ใน `src/ai_fishing.py` อ่าน key จาก `.env` โดยไม่ต้องเพิ่ม dependency ใหม่
- เมื่อเริ่มวันใหม่และเปิดหน้าเควสต์ ระบบลองเรียก Gemini ก่อนถ้ามี key; ถ้าสำเร็จใช้เควสต์จาก Gemini แต่ถ้าไม่มี key หรือ API ล้มเหลวจะใช้เอเจนต์ในเครื่องแทน
- เรียก Gemini ในเธรดเบื้องหลังเพื่อไม่ให้ GUI ค้าง และลองซ้ำสูงสุด 3 ครั้งสำหรับข้อผิดพลาดชั่วคราว เช่น HTTP 503
- เพิ่มปุ่มทดสอบ Gemini ที่ด้านบนหน้าเควสต์ ควบคุมด้วย `ENABLE_GEMINI_TEST_BUTTON` (ค่าเริ่มต้น `True`); เมื่อกดจะได้ชุดเควสต์ใหม่แทนชุดเดิม จาก Gemini เมื่อสำเร็จ หรือจากเอเจนต์ในเครื่องเมื่อ API ล้มเหลว
- แสดงสถานะการเชื่อมต่อเป็นข้อความบนหน้าเควสต์ (ไม่มี popup) และบันทึกผลตรวจไว้ในเซฟ จึงไม่เรียก API อัตโนมัติซ้ำเมื่อกลับเข้าหน้าในวันเดียวกัน; ปุ่มทดสอบยังสั่งสร้างชุดใหม่ได้
- หน้าเควสต์แสดงเควสต์ 1–5 รายการ โดยแต่ละรายการอยู่ในการ์ดของตัวเอง มีรายละเอียด ความคืบหน้า แถบสี รางวัล และปุ่มรับรางวัลแยกกัน
- เควสต์ ความคืบหน้า และสถานะรับรางวัลถูกบันทึกในข้อมูลเกม เพื่อให้ชุดเควสต์ของวันเดิมไม่เปลี่ยนเมื่อปิดแล้วเปิดเกมใหม่
- การสุ่มปลาเพิ่มโอกาสเลือกปลาชนิดที่ผู้เล่นจับได้น้อยในแหล่งน้ำนั้น

## ประเภทเควสต์

ชุดประจำวันสร้างเมื่อวันที่ในเซฟไม่ตรงกับวันที่ปัจจุบัน โดยใช้ Gemini ก่อนเมื่อมี key และใช้เอเจนต์ในเกมเป็น fallback หาก Gemini ใช้งานไม่ได้ Gemini เลือกประเภทและตั้งชื่อ ส่วนเกมตรวจความถูกต้องและคำนวณจำนวนเป้าหมาย น้ำหนัก และรางวัลเอง ปุ่มทดสอบ Gemini สั่งสร้างชุดใหม่ทันที: API สำเร็จจะแทนชุดเดิมด้วยชุดจาก Gemini; หาก API ล้มเหลวจะสุ่มชุดใหม่จากเอเจนต์ในเครื่องแทน

เอเจนต์ในเครื่องสุ่มจำนวนเควสต์จาก 1 ถึง 5 รายการ ส่วน Gemini จะเลือก 1 ถึง 5 รายการจากประเภทที่รองรับ ทั้งสองแบบไม่เลือกประเภทซ้ำ:

1. **นักสำรวจน้ำจืด** — จับปลาในทะเลสาบน้ำจืด
2. **นักล่าปลาทะเล** — จับปลาในทะเลลึก
3. **ผู้พิชิตปากแม่น้ำ** — จับปลาในปากแม่น้ำน้ำกร่อย
4. **ออกเรือหาปลา** — จับปลาที่แหล่งน้ำใดก็ได้
5. **นักตกปลาร่างยักษ์** — จับปลาที่มีน้ำหนักถึงเกณฑ์

ปลาหนึ่งตัวอาจเพิ่มความคืบหน้าให้หลายเควสต์ได้ หากตรงกับเงื่อนไขของแต่ละรายการ เช่น ปลาทะเลที่หนักพออาจนับทั้งเควสต์ทะเล เควสต์ปลาหนัก และเควสต์จับปลาทั่วไป

## สูตรความยากและรางวัล

กำหนดระดับรวมของอุปกรณ์เป็น:

```text
level_score = max(0, bait_level + rod_level - 2)
```

จำนวนปลาเป้าหมายของเควสต์ทั่วไปและเควสต์แหล่งน้ำ:

```text
target = 2 + level_score
```

เควสต์ปลาหนักกำหนดจำนวนเป้าหมายและน้ำหนักขั้นต่ำแยกดังนี้:

```text
target = 1 + floor(level_score / 3)
min_weight_kg = 4.0 + 0.5 * (bait_level - 1) + 1.5 * (rod_level - 1)
```

ฐานเงินรางวัลขึ้นกับประเภทเควสต์:

```text
reward_base = 60   # เควสต์จับปลาทั่วไป
reward_base = 90   # เควสต์แหล่งน้ำ
reward_base = 140  # เควสต์ปลาหนัก
```

สูตรเงินรางวัลสุดท้าย:

```text
reward = reward_base + 25 * target + 20 * level_score
```

ดังนั้นการเพิ่มเลเวลเหยื่อหรือคันเบ็ดจะเพิ่ม `level_score` ทำให้จำนวนเป้าหมายหรือเกณฑ์น้ำหนักสูงขึ้น และเพิ่มเงินรางวัลด้วย เควสต์แต่ละรายการรับรางวัลได้ครั้งเดียว

## สูตรสุ่มปลา

1. สุ่มชนิดปลาจาก API หรือข้อมูลสำรองในแหล่งน้ำที่เลือกจำนวน 3 ครั้ง
2. นับจำนวนปลาของแต่ละชนิดที่มีอยู่ในกระเป๋าในแหล่งน้ำนั้น
3. เลือกจากชนิดที่มีจำนวนในกระเป๋าน้อยที่สุดในตัวเลือกทั้งสาม หากเสมอกันจะสุ่มเลือกจากกลุ่มที่เสมอ

วิธีนี้ยังคงสุ่มปลาได้ผ่าน `SpeciesLoader` ระหว่างที่ข้อมูลออนไลน์กำลังโหลด และให้น้ำหนักไปทางชนิดที่ผู้เล่นยังมีน้อย

## ไฟล์หลักที่เกี่ยวข้อง

- `src/ai_fishing.py` — สร้างเควสต์ ติดตามความคืบหน้า รับรางวัล และเลือกชนิดปลา
- `src/gui/pages/quest.py` — แสดงการ์ดเควสต์และแถบความคืบหน้า
- `src/gui/pages/fishing.py` และ `src/gui/presenter.py` — เชื่อมการสุ่มปลาและการจับปลากับเอเจนต์
- `src/game_state.py` — บันทึกข้อมูลเควสต์ไปกับเซฟเกม
- `src/gui/app.py` — สร้างเอเจนต์และลงทะเบียนหน้าเควสต์
- `src/gui/pages/` — แยกโค้ดหน้าจอ GUI เป็นไฟล์ตามแต่ละหน้า
- `.env` และ `.gitignore` — ตั้งค่า Gemini ในเครื่องและป้องกัน key จริงถูก commit
- `README.md` — วิธีตั้งค่า key และวิธีใช้การสร้างเควสต์ด้วย Gemini

## การตรวจสอบ

ตรวจ `git diff --check` แล้วผ่าน และทดสอบเรียก Gemini API จริงสำเร็จหนึ่งครั้ง
โดยใช้ `generate_gemini_quests(apply=False)` เพื่อยืนยันการเชื่อมต่อและรูปแบบคำตอบ
โดยไม่เปลี่ยนเควสต์หรือไฟล์เซฟ ยังไม่ได้รันชุดทดสอบหรือเปิด GUI ตรวจด้วยตนเอง
