Sprint 2 - PixelPaw Virtual Pet (Back-End: API + File I/O + ตรรกะการเลี้ยง)

ทุกคำสั่งด้านล่างให้รันจากโฟลเดอร์นี้ (Sprint2/code)

เตรียมก่อนเล่น
    pip install -r requirements.txt
    ตั้งค่า API Key (ดูตัวอย่างในไฟล์ .env.example)
        Windows PowerShell : $env:GEMINI_API_KEY = "คีย์ของคุณ"
        Command Prompt     : set GEMINI_API_KEY=คีย์ของคุณ

วิธีเล่นเกม
    python main.py

วิธีรันชุดทดสอบ (ไม่ต้องใช้ API Key ไม่ต้องต่อเน็ต)
    python -m pytest -q

วิธีตรวจสอบมาตรฐานโค้ด (PEP 8)
    flake8 .

วิธีทดสอบการเชื่อมต่อ API ด้วยมือ (ต้องใช้ API Key จริง)
    python tools/check_api_connection.py

วิธีเปิดรายงานประจำสปรินต์
    jupyter notebook ../notebook/Sprint2_Report.ipynb
    (ต้องรันเซลล์แรกสุดก่อนเสมอ เพราะเซลล์นั้นจะย้ายไปทำงานที่โฟลเดอร์ code ให้)
