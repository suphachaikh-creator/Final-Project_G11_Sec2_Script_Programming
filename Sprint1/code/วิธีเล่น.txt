Sprint 1 - PixelPaw Virtual Pet CLI (Front-End เท่านั้น)

ทุกคำสั่งด้านล่างให้รันจากโฟลเดอร์นี้ (Sprint1/code)

วิธีรันโปรแกรม
    python main.py

วิธีรันชุดทดสอบ
    pip install -r requirements.txt
    python -m pytest -q

วิธีตรวจสอบมาตรฐานโค้ด (PEP 8)
    flake8 .

วิธีเปิดรายงานประจำสปรินต์
    jupyter notebook ../notebook/Sprint1_Report.ipynb
    (ต้องรันเซลล์แรกสุดก่อนเสมอ เพราะเซลล์นั้นจะย้ายไปทำงานที่โฟลเดอร์ code ให้)

หมายเหตุ
    Sprint 1 ยังไม่เรียก API จริงและยังไม่บันทึกไฟล์จริง
    ส่วนที่เชื่อม API + บันทึก JSON + ตรรกะการเลี้ยงจริง อยู่ในโฟลเดอร์ Sprint2/code
